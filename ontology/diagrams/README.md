# Historical ontology illustrations

These existing illustration assets are retained for reference. The automatic
Python diagram generator and its optional dependency have been removed. New
ontology figures are managed by the author; no maintained command regenerates
this directory. These images are not experimental measurements.

The maintained ontology/file reference is in `docs/ONTOLOGY_DISTRIBUTION.md` and
`docs/ONTOLOGY_REVIEW.md`; benchmark PNG outputs are described in `docs/OUTPUTS.md`.
